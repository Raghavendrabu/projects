## 📂 Project Catalog

### 🤖 AI, Machine Learning & Computer Vision
- **[exam-cheating-detection-main](exam-cheating-detection-main/)** – Computer-vision-powered automated proctoring system using real-time face, audio, and gaze detection with alerting and MongoDB logging.
- **[pqc_medical_imaging_system](pqc_medical_imaging_system/)** – Post-Quantum Cryptography medical imaging framework combining hybrid encryption (Kyber/Dilithium) with secure image handling.
- **[stock_price_lstm_pbl](stock_price_lstm_pbl/)** – Stock price prediction model employing Long Short-Term Memory (LSTM) recurrent neural networks.
- **[birthday-assistant](birthday-assistant/)** – Interactive AI assistant web application built with Flask for managing birthdays, scheduling wishes, and intelligent reminders.
- **[ai-task-manager](ai-task-manager/)** – Intelligent task management system for automated task classification, prioritization, and tracking.
- **[lab](lab/)** – Machine learning lab implementations and algorithms (ANNs, MLP, data normalization, classification models).
