Consent-Based Screen Sharing

Web browsers enforce strict security controls when sharing screens. When you request a screen stream, the browser automatically displays a permission prompt asking the user to choose exactly what to share.

Key Privacy & Consent Features:

  • Explicit User Action: Sharing can only be initiated by a physical interaction (e.g., clicking the "Start Screen Share" button).
  • Native Permission Dialog: The browser manages the selection dialog. The user chooses whether to share their entire screen, a specific window, or a single browser tab.
  • Visual Indicators: Browsers show persistent visual indicators (like a red dot in the tab or a system tray notification) highlighting that a screen share is active.
